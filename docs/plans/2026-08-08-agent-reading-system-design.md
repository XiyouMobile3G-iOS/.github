# Agent 阅读体系设计

## 目标

为 `XiyouMobile3G-iOS/.github` 建立仅服务当前仓库的轻量 Agent 阅读体系，让 Agent 在编辑组织首页前快速获得稳定、准确的上下文。

## 文件与职责

- `AGENTS.md`：仓库级自动入口，规定必读顺序、仓库目标、修改边界、工作流程和验证清单。
- `memory.md`：记录组织身份、仓库现状、长期内容决策和待确认事项，不保存敏感信息，也不复制首页正文。
- `profile/README.md`：GitHub 组织首页内容的唯一事实来源。

## 阅读顺序

1. 阅读根目录 `AGENTS.md`，理解工作约束。
2. 阅读根目录 `memory.md`，获取稳定背景和既有决策。
3. 阅读 `profile/README.md`，确认当前实际页面内容。

## 维护原则

- 首页结构、目标受众或长期设计决策发生变化时，同步更新 `memory.md`。
- 普通措辞、标点和格式微调不进入 `memory.md`。
- `memory.md` 不保存 Token、凭据、成员隐私或其他敏感数据。
- 修改组织首页后检查链接、Markdown/HTML 结构和变更范围。

## 非目标

- 不建设跨仓库通用模板。
- 不引入脚本、自动化工具或复杂文档层级。
- 本次不修改 `profile/README.md` 的展示内容。
